# Brand: app icon and site mark

Every icon of the app and the site is generated from one glyph. Don't edit the generated files by hand.

- `ACTIVE`: one line naming the glyph in use (a folder here). Now `drabinka` (D · Drabinka, chosen by the owner, Q38).
- `<name>/glyph.svg`: the master artwork, a 1024 × 1024 artboard with the glyph in the accent color `#D1FF00` on a transparent background. One outline with even-odd holes, so no shapes overlap.
  - `drabinka/`: the progression ladder; the rungs brighten towards the top (a vertical opacity gradient).
  - `pinezka/`: C · Pinezka parku, a map pin with a pull-up bar and a head cut out. Kept ready as the alternative.

## Build

```sh
(cd site && npm ci)                      # once: the script renders with sharp from site/node_modules
node scripts/brand/build-icons.mjs       # add --previews <dir> for default/dark/tinted and 29/40/60 px PNGs of every glyph
```

It writes:

| output | what |
|---|---|
| `cali-park/Resources/AppIcon.icon/` | Icon Composer bundle: background fill `#121212`, one glass group with the glyph. actool compiles it into the Liquid Glass icon for iOS 26 and flattens it into the default, dark and tinted images for iOS 18. |
| `cali-park/Resources/Assets.xcassets/AppIcon.appiconset/` | 1024 px default (glyph on `#121212`), dark and tinted (transparent background) PNGs. While `AppIcon.icon` exists, actool uses only the `.icon`; the appiconset is the plain fallback if the `.icon` is ever removed. |
| `site/app/icon.svg`, `site/public/brand/mark.svg` | the favicon and the site header/footer mark (the icon on a rounded tile) |
| `site/public/brand/app-icon.svg` | full-bleed icon, the source of `site/app/apple-icon.png` |
| `site/app/opengraph-image.png`, `site/app/apple-icon.png` | regenerated by `npm run og`, which the script runs |

## Switching the icon

Put another folder name in `ACTIVE` (e.g. `pinezka`), run `node scripts/brand/build-icons.mjs`, build, and commit the regenerated files. Nothing else changes: `site/components/Wordmark.tsx` and `site/scripts/make-og.mjs` read the generated files.

## Adding a glyph

Add `<name>/glyph.svg` on the same 1024 artboard, keep it inside roughly 200–870 vertically and horizontally (the iOS mask cuts the corners), use only `#D1FF00` (the script recolors it for the tinted and preview variants), and check the 29 px preview.
