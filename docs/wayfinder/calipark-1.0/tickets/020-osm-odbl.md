# Import z OSM i otwarte dane Parków (ODbL)

## Pytanie

Czy zasilamy mapę z OpenStreetMap, skoro licencja ODbL wymaga wtedy udostępnienia danych Parków (położenie, nazwa, sprzęt, status, razem ze Zgłoszeniami użytkowników) jako darmowego pliku do pobrania? Opinie, oceny i zdjęcia zostają nasze.

Alternatywa: bez OSM, czyli start z pustą mapą wypełnianą tylko przez ekipę i Zgłoszenia.

Kontekst: „Parki z OpenStreetMap w Polsce i licencja ODbL” (ok. 390 pewnych Parków w Polsce).
